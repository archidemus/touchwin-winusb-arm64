# Dependencias externas

Este repositorio distribuye una implementación independiente del puente y sus scripts. Los nombres LPC2400_* identifican la interfaz usada para interoperabilidad.

TouchWin, la DLL original de XINJE, firmware, Windows, WinUSB, LLVM y Windows SDK no se redistribuyen aquí. Se deben obtener legalmente de sus distribuidores y respetar sus licencias. LICENSE no concede derechos sobre ellos.

Los nombres comerciales identifican compatibilidad; no implican afiliación o respaldo.
